# Golden Gate

*"The only thing to think about is if there are more than 2 dnas going in. If so, you premix 2
or 3 uL of each dna as a 'DNA premix' then use 2 uL of that in the reaction."* — JCA, 2026-09-10

| DNAs in | setup |
|---|---|
| 2 | add each directly to the reaction |
| 3 or more | **a DNA premix**: 2–3 µL of each DNA in one tube, then 2 µL of that premix into the reaction |

The reason is volume: a 10 µL reaction cannot absorb six separate DNA additions and still hold
its buffer and enzymes. The premix collapses them into one 2 µL addition.

Everything else — enzyme, buffer, ligase, program — comes straight from the construction file and
the protocol module. Count the DNAs; that is the only decision.

See `gibson.md`: the same rule, for the same reason.
