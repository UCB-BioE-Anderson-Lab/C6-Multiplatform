# Zymo cleanup

*"Nothing to think about there. It's simple, just make up tube names."* — JCA, 2026-09-10

One tube per input, named from the input. The convention already in use is a `z` prefix —
`pcr15` → `zpcr15` — and the value of a convention here is only that the name is derivable, so
that the next step's sheet can refer to it without a lookup table.

Carry the elution volume through; it is what the next step's input concentration depends on.
